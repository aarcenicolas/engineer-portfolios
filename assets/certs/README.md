# Certificates

PDFs or image scans of diplomas and certifications.

Drop the file here, then add `fileUrl` to that certification in `index.html`:

    fileUrl:"assets/certs/google-data-analytics.pdf"

A "View Certificate ↗" link appears on that row automatically.
